# Ressources mobiles

`images/` contient neuf photos et éléments visuels extraits des SVG du dossier local `05-Menu--Etudiant`, sélectionnés pour le catalogue mobile. `splash-logo.png` est le logo PNG transparent intégré dans le même export Figma. Le script `../scripts/extract_assets.py` recrée ces ressources à partir des exports avec Pillow.
