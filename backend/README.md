# Backend — Mon Miam Miam

API REST Laravel du projet Mon Miam Miam.

## État du travail

Ce dossier contient une base de projet Laravel 12 **à installer localement**.
L'installation des dépendances, l'exécution MySQL et les tests doivent être vérifiés sur une machine avec Composer et MySQL.

Voir [INSTALLATION.md](INSTALLATION.md) pour les commandes, et [docs/DECISIONS_BACKEND.md](docs/DECISIONS_BACKEND.md) pour les décisions techniques.
