# Site public

Les pages `/`, `/menu` et `/promotions` reprennent les trois dossiers `--Public` de l'export `app1-tous-les-ecran222s/screens`. Les ressources et les aperçus d'origine sont dans `frontend/public/figma-public/`.

La navigation, la recherche, les filtres, le tri, la pagination, les favoris locaux, les conditions des offres et le choix des cookies fonctionnent côté navigateur. `/acces` explique l'état actuel des parcours de connexion et d'inscription : aucun compte ou commande n'est créé sans backend. `/admin` ouvre le back-office de démonstration.
