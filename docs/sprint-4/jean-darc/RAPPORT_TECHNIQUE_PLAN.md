# Rapport technique consolidé — Mon Miam Miam

**Auteur et déposant :** Jean d'Arc Kazamba  
**Statut :** plan de rédaction, **pas** rapport final validé.

## 1. Contexte et périmètre

Décrire les besoins des étudiants, employés, gérants et administrateurs, le MVP et le périmètre réellement livré. Référencer les stories Jira PMEE-47 à PMEE-53.

## 2. Architecture

Documenter le frontend React/Vite, l'application React Native/Expo, le backend Laravel et MySQL, les flux de données et les configurations par environnement. Joindre un schéma d'architecture versionné.

## 3. Conception et API

Présenter modèle de données, migrations, contrats d'API, authentification et permissions par restaurant, erreurs et sécurité. Ne pas déclarer implémentés les endpoints uniquement documentés.

## 4. Réalisation par sprint

- Sprint 1 : conception, maquettes, versioning, backlog.
- Sprint 2 : socle React/Laravel, conventions, Jira/CI, API et données à vérifier.
- Sprint 3 : web étudiant, back-office, interfaces employé/gérant, mobile et API métier ; distinguer code en PR et code intégré.
- Sprint 4 : intégration, tests, conteneurisation, déploiement et rapport final.

## 5. Vérification et qualité

Joindre les commandes exactes et résultats réels de lint, build, tests Laravel, tests API, intégration, mobile et E2E ; conserver logs et date. Ne pas inventer des taux de couverture ou des tests réussis.

## 6. Déploiement, risques et limites

Décrire la configuration de développement/production, la gestion des secrets, les procédures de rollback et les écarts non résolus.

## 7. Conclusion et annexes

Référencer les PR fusionnées, les issues clôturées avec preuves, les captures et les décisions d'équipe. Ajouter les procédures d'installation et de recette.
