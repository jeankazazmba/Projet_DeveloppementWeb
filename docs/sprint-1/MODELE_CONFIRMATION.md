# Modèle de commentaire à publier dans l'Issue

**Sprint 1 — Livraison de conception**

- **Responsable :** @identifiant
- **Issue :** #NUMERO
- **Travail réalisé :** résumé factuel
- **Fichiers déposés :** liens GitHub vers les fichiers
- **Pull Request :** lien vers la PR
- **Preuves :** captures, tests de cohérence, liens Figma/Jira, schémas
- **Décisions / difficultés :** préciser les points ouverts
- **Relecture demandée à :** @identifiant

**État :** livré pour revue, en attente de validation.

> Ne pas écrire « validé » tant que la revue n'a pas été réalisée.
