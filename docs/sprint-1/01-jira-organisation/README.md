##  1. Présentation du projet
**Mon Miam Miam** est une application dédiée à un service de restauration. L'objectif de l'organisation actuelle est de structurer le travail d'équipe en répartissant les tâches, en assurant un suivi rigoureux de l'avancement, en centralisant les décisions et en reliant le suivi du projet au code source hébergé sur GitHub.
 * **Jira Cloud** sert de référence unique pour la gestion des tâches, les responsables, les priorités et l'avancement global.
 * **GitHub** sert de référence pour le code source, la gestion des branches, les commits et les pull requests (PR).

##  5. Recommandations de structuration des tickets
Pour garantir un suivi clair et efficace, chaque ticket Jira doit être enrichi avec :
 1. Une **User Story** ou un objectif clairement formulé.
 2. Une **description compréhensible** précisant le résultat attendu.
 3. Des **critères d’acceptation** mesurables et vérifiables.
 4. Un **responsable principal**, une **priorité** et une **échéance réaliste**.
 5. Une **estimation de l'effort** (Story Points) et l'identification des dépendances.
 6. Des **liens utiles** (maquettes Figma, documentation, PR).
 7. Les **tests à effectuer** avant le passage au statut *Terminé*.
