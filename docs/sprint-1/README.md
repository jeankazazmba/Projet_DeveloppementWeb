## Procédure obligatoire
1. Créer une branche `docs/NUMERO-issue-nom` à partir de `main`.
2. Ajouter les vrais fichiers dans le dossier correspondant (pas de documents fictifs). Ne pas ajouter de secrets, mots de passe, données personnelles ni jetons.
3. Ouvrir une Pull Request vers `main` avec `Refs #NUMERO`, demander une relecture et intégrer après validation.
4. Dans l'Issue assignée, commenter avec le lien vers la PR, les fichiers et une courte synthèse, puis demander validation.
5. Le coordinateur vérifie les critères, peut demander des corrections, puis ferme l'Issue en **Completed** si tout est conforme.
