## Règles de remise

- Déposer ici les documents, captures, rapports et preuves de tests, pas le code source exécutable.
- Le code reste dans `frontend/`, `backend/` ou `mobile/`, via une branche dédiée et une pull request.
- Nommer les preuves avec la date et le scénario testé ; ne jamais déposer de secrets ni de données personnelles.
- Préciser pour chaque livraison : lien PR, commit SHA, ticket Jira, état (non commencé / en cours / à revoir / validé), date et relecteur.
- Indiquer explicitement les fonctionnalités simulées et les API non intégrées.
- La validation du livrable requiert une revue et des preuves de tests, pas uniquement une capture.
