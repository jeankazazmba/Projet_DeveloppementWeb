# 03-administration

Dossier des livrables et preuves de recette du Sprint 3.

La [spécification fonctionnelle de l'administration](SPEC_FONCTIONNELLE_ADMIN.md) détaille les fonctionnalités du cahier, les écrans présents, les écarts et la structure proposée pour relier l'admin au backend multi-restaurants.

La [répartition des responsabilités par utilisateur](RESPONSABILITES_PAR_ROLE.md) distingue les rôles du cahier V1.0.2 de l'administration de plateforme ajoutée ensuite et fixe la frontière des données entre plateforme et restaurants.

Déposer ici les documents, captures, décisions, scénarios et résultats de tests du module. Le code applicatif reste dans les dossiers frontend/, backend/ ou mobile/.

Pour la répartition et les références Jira/GitHub, consulter [l'index du Sprint 3](../README.md).
